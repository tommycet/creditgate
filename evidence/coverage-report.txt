## Reproduce

```bash
export PATH="$HOME/.foundry/bin:$PATH"
cd /root/flare-hackathon/creditgate
forge coverage                 # prints the percentage table above
forge coverage --report lcov   # writes ./lcov.info (machine-readable)
```

If `forge coverage` reports a compiler error on first run, run `forge clean && forge cache
clean` first — Foundry's incremental solc cache can serve a stale unit when the optimizer
setting is toggled for coverage (Foundry disables `optimizer` + `viaIR` for accurate
line-instrumentation, which triggers a full recompile). This is a known Foundry quirk, not a
project defect.
